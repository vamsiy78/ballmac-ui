# Figma kit: how it is made

The kit has three layers. The first two are generated by scripts in this repository; the third needs a designer.

| Layer | What | Made by | Delivered |
| --- | --- | --- | --- |
| Tokens | Every theme as W3C design tokens (`color.light`, `color.dark`, radius, spacing, motion) | `pnpm figma:tokens` | Licensed download: `/r/pro/kits/ballmac-figma-tokens.tar.gz` |
| Captures | Every component, block and template as PNG and HTML at 1440 and 390 px, light and dark, with a manifest | `pnpm figma:capture` | Too large for the site (several hundred MB for everything): host the archive yourself |
| Library | Figma components with auto-layout, variants and the tokens bound as variables | A designer in Figma, using the layers above | Not built yet |

## Tokens

```bash
pnpm figma:tokens            # writes figma-kit/tokens/<theme>.tokens.json and index.json
```

- 13 themes: `default` and the twelve presets. Each file is standalone.
- `color.light.*` and `color.dark.*` are the two modes. Chart colours are `color.light.chart.1` to `.5`.
- Colours are sRGB hex (Figma's colour space). The original value and the CSS variable are in `$extensions.ballmac` so nothing is lost: `oklch(0.556 0.15 248)` and `--primary`. Colours with transparency (the dark borders) use an 8-digit hex.
- `radius` follows the components' scale (`sm = radius − 4px`, `md = radius − 2px`, `lg = radius`, `xl = radius + 4px`), `motion` holds the durations and easings, `spacing.unit` is the Tailwind step.
- `apps/www/tests/figma-tokens.test.ts` checks every theme: complete, valid hex, and the contrast the theme engine promises still holds after rounding to 8-bit hex.

Use a Figma plugin that imports W3C design tokens (Tokens Studio is one), create one collection with two modes, and map `color.light` and `color.dark` to them. Check whether your version of Figma can also import design token files directly: that changes quickly and is worth a look before installing a plugin.

## Captures

Start the site with Pro present (`pnpm build`, then `pnpm --filter @ballmac-ui/www exec next start -p 3400`), then:

```bash
pnpm figma:capture --base-url http://localhost:3400                          # everything, first example of each item
pnpm figma:capture --base-url http://localhost:3400 --tier pro --examples all  # every Pro variant
pnpm figma:capture --base-url http://localhost:3400 --filter hero-pro,button   # a subset
```

Output in `figma-kit/`: `captures/<category>/<item>/<example>.<width>.<mode>.png|html` and `manifest.json` (items, variants, files, pixel sizes).

- Blocks and templates are captured at full height. Components are cropped to the component with a little space around it.
- Animations are set to reduced motion so every capture shows the settled state.
- The HTML files have scripts removed and link one shared stylesheet in `captures/assets/`; images and fonts keep pointing at the site address, so they show when the site is reachable. Tools that turn HTML into Figma layers can read them.
- Re-running skips files that exist. Use `--force` to redo them.

## Building the library

This part needs Figma and a designer. Suggested order: import tokens; build the primitives (button, input, checkbox, switch, select, badge, avatar, card) with variants for state and size, bound to the token variables; then use the captures as the reference for blocks and templates. Rebuild the tokens and captures after any theme or component change.

## Not included

No Figma file is produced here, and the kit does not include fonts: the components use the system font stack unless a theme sets one.
