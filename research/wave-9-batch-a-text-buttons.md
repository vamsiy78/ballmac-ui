# Wave 9, batch A: text effects and buttons

Reviewed 2026-10-01. All 12 components are original Ballmac code built on Motion and the Ballmac `button`. No code was copied from Aceternity, Tailwind Plus, any Pro kit or anything unlicensed, and none were adapted from Magic UI or Motion Primitives source, so none carry a "Based on" header; only the ideas (what the effect is called and roughly what it does) overlap. Patterns were compared with [Magic UI](https://magicui.design/docs/components), [Motion Primitives](https://motion-primitives.com/), [Aceternity](https://ui.aceternity.com/components) (visual ideas only), [Cult UI](https://www.cult-ui.com/docs), [Kibo UI](https://www.kibo-ui.com/components), [21st.dev](https://21st.dev/community/components), [Rough Notation](https://roughnotation.com/) for the highlighter idea, and real marketing sites.

Shared design decisions for the whole of Wave 9: every animation has a reduced-motion path that shows the final state (or a still equivalent) and every infinite animation stops under it; decorative pieces are `aria-hidden` and `pointer-events-none`; text effects keep the real text in a hidden element so screen readers read it once; random values are picked after mount, never during render, so server and browser markup match; colors come from theme tokens (`chart-1` to `chart-5`, `foreground`), not hex; and buttons are built on the Ballmac `button`, so sizes, variants, loading and focus rings keep working.

| Component | Competitor pattern studied | Ballmac improvement |
| --- | --- | --- |
| Blur Fade | Magic UI Blur Fade | Four-direction travel, and `BlurFadeGroup` that staggers any children and keeps their keys; content is in the DOM from the start and shown at once under reduced motion |
| Text Animate | Magic UI Text Animate, Motion Primitives text effects | Character, word or line splitting with eight entrances, real text kept for screen readers, words never break across lines when animating by character |
| Typing Text | Magic UI Typing Animation | Types and erases several strings with uneven human timing, caret that stops when finished, starts on scroll, and shows whole text with no caret under reduced motion |
| Hyper Text | Magic UI Hyper Text | A split-flap board: characters flip in place and settle left to right, optional tiles, and a hover trigger that is keyboard-focusable and replays on focus |
| Sparkles Text | Magic UI Sparkles Text | Stars re-roll their position after each twinkle, use theme colors, optional gradient fill; none render for reduced motion and nothing random runs during render |
| Morphing Text | Magic UI Morphing Text | The same blur and threshold morph, but the box is sized by hidden copies of every text so nothing jumps, and the loop stops off screen and under reduced motion |
| Spinning Text | Magic UI Spinning Text, Aceternity circular text ideas | Text fitted to the circle by length, a center slot for a logo, pause on hover, named image for screen readers |
| Highlighter | Rough Notation, Magic UI Highlighter | Six marks (highlight, underline, box, circle, strike, bracket) drawn in real pixels so stroke width and the draw-on animation stay true at any text size; text keeps the foreground color |
| Rainbow Button | Magic UI Rainbow Button | Built on the Ballmac button (all sizes, variants, pill shape), theme-color rotating border, glow on hover and keyboard focus, still gradient under reduced motion |
| Shiny Button | Magic UI Shiny Button | A light sweep on hover and focus, or a timed loop, on any button variant; nothing drawn under reduced motion |
| Pulse Button | Magic UI Pulse Button | Rings that calm as soon as the button is hovered or focused, can be switched off once the person acts, and stay a still faint ring under reduced motion |
| Ripple | Magic UI Ripple, Material touch ripple | Both a concentric background and a press ripple wrapper that starts at the pointer, or the center for keyboard activation |

Accessibility notes: axe (serious and critical) is clean on every `/preview/*` page in light and dark, and `scripts/a11y-open-states.ts` waits for each animation to finish before scanning, so mid-fade text is not mistaken for low contrast. Findings that shaped the final code: a block-level morphing text inside a paragraph caused a hydration error (it is now a `span`), the split-flap characters stuck at zero opacity when a presence animation was interrupted (replaced with a keyed entrance), and a dash-length bug with non-scaling strokes cut the underline in two (the highlighter now draws in measured pixels).
