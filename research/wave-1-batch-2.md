# Wave 1 batch 2: interaction foundations

Reviewed 2026-09-30. Source license checked: shadcn/ui and Radix Primitives are MIT. The Ballmac wrappers, styling, and examples in this batch were written for this registry; no Aceternity, Tailwind Plus, Pro, or unlicensed source code was copied. Patterns were compared with the [shadcn Radix catalog](https://ui.shadcn.com/docs/components), [DaisyUI catalog](https://daisyui.com/components/), [ReUI](https://reui.io/components/), [coss UI (formerly Origin UI)](https://coss.com/ui), [Magic UI catalog](https://magicui.design/docs/components), [Motion Primitives animated background](https://motion-primitives.com/docs/animated-background), [Aceternity catalog](https://ui.aceternity.com/components), [Cult UI](https://www.cult-ui.com/docs), [Kibo UI](https://www.kibo-ui.com/components), [21st.dev](https://21st.dev/community/components), [Tailwind Plus](https://tailwindcss.com/plus/ui-blocks/application-ui), and [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/). Magic UI and Aceternity focus more on display effects than accessible form primitives, so their contribution here is the expectation of a compelling demo and restrained motion.

| Component    | Competitor pattern studied                                    | Ballmac improvement                                                                                            |
| ------------ | ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Alert Dialog | shadcn modal confirmation and media; ReUI destructive actions | Token-based risk emphasis, action hierarchy, focused cancel behavior, and a real project removal demo          |
| Button Group | shadcn grouped controls; DaisyUI Join                         | Compact adjacent controls, optional labels/separators, responsive demo, and visible per-control focus          |
| Collapsible  | shadcn/Radix disclosure; DaisyUI Collapse                     | Product-specific detail panel, controlled/uncontrolled use, and reduced-motion-aware reveal                     |
| Hover Card   | shadcn/Radix Hover Card; Aceternity link preview              | Useful keyboard-focus preview with stable information and no hover-only essentials                             |
| Popover      | shadcn/Radix Popover; Motion Primitives morphing popover      | Focus-managed editor surface, constrained mobile width, header composition, and token-based open motion        |
| Radio Group  | shadcn radios; ReUI rich option cards; DaisyUI Radio          | Labeled option cards with descriptions and large click targets around native Radix keyboard behavior           |
| Scroll Area  | shadcn/Radix Scroll Area; DaisyUI overflow containers         | Focusable named reading region, theme-aware thumb, and realistic activity feed                                  |
| Tabs         | shadcn/Radix Tabs; DaisyUI tabs; Aceternity animated tabs     | Quiet selected indicator, reduced-motion transitions, and useful dashboard content instead of placeholder tabs |
| Toggle       | shadcn/Radix Toggle; DaisyUI Toggle                           | Clear pressed state, icon-plus-label demo, and compact size/variant options                                    |
| Toggle Group | shadcn/Radix Toggle Group; ReUI variants; DaisyUI Join        | Single or multiple selection, roving keyboard focus, clear pressed state, and practical view-mode demo         |

Accessibility foundation: [Radix Primitives](https://www.radix-ui.com/primitives) handles focus, ARIA, and keyboard patterns for overlays and composite widgets. [shadcn's current component docs](https://ui.shadcn.com/docs/components) informed API names. [shadcn license](https://github.com/shadcn-ui/ui/blob/main/LICENSE.md) and [Radix license](https://github.com/radix-ui/primitives/blob/main/LICENSE) were reviewed before implementation.
