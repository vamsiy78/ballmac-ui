# Wave 5: navigation and layout

Reviewed 2026-09-30. All 14 components are original Ballmac compositions over licensed primitives already in the registry (Radix via `radix-ui`, cmdk, Motion, and the Ballmac `navigation-menu`, `sheet`, `dropdown-menu`, `command`, `kbd`). No code was copied from Aceternity, Tailwind Plus, Magic UI Pro or any unlicensed source, so none carry a "Based on" header. Patterns were compared with the [shadcn catalog](https://ui.shadcn.com/docs/components) (navigation menu, sidebar, breadcrumb, command), [DaisyUI](https://daisyui.com/components/) (navbar, drawer, menu, dock), [ReUI](https://reui.io/components/), [coss UI (Origin UI)](https://coss.com/ui), [Magic UI](https://magicui.design/docs/components) (dock, scroll progress, marquee ideas), [Motion Primitives](https://motion-primitives.com/), [Aceternity](https://ui.aceternity.com/components) (floating navbar, sticky scroll reveal and container scroll: studied for the interaction idea only, implemented from scratch), [Cult UI](https://www.cult-ui.com/docs), [Kibo UI](https://www.kibo-ui.com/components), [21st.dev](https://21st.dev/community/components), [Tailwind Plus](https://tailwindcss.com/plus/ui-blocks/marketing/elements/headers) (header and flyout demos only) and [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/sidebars).

A shared lib, `scroll` (`useScrolled`, `useScrollDirection`, `useScrollSpy`, `scrollToId`), keeps the scroll-aware pieces consistent, honors reduced motion, and supports a `container` ref so the same components work inside panels, previews and the page.

| Component | Competitor pattern studied | Ballmac improvement |
| --- | --- | --- |
| Navbar | DaisyUI navbar; Tailwind Plus headers; Vercel/Linear headers | Border and shadow only after the page moves, optional hide-on-scroll that stays visible on focus, mobile links in a labelled sheet that closes on choice, active link with `aria-current` and an animated underline |
| Mega Menu | shadcn navigation menu; Stripe/Vercel flyouts; Tailwind Plus flyouts | Data-driven panels (columns, described links, badges, featured card) on Radix Navigation Menu with a centered shared viewport, plus a native-`details` mobile list that works without JavaScript |
| Floating Nav | Aceternity floating navbar (idea only); Magic UI dock | Spring-gliding indicator, top or bottom, auto-hide that never hides while focused, labels collapse to icons but stay as accessible names, reduced-motion fallbacks |
| App Shell | shadcn sidebar layouts; Vercel/Linear app frames | Skip link, landmarks, sticky panels that scroll independently, sidebar that becomes a named sheet, all sizes through CSS variables |
| Team Switcher | shadcn sidebar team switcher; Linear/Notion workspace menus | Radio-menu semantics with logos and descriptions, add row, compact rail mode with an accessible name, controlled or uncontrolled |
| Sticky Scroll | Aceternity sticky scroll reveal (idea only); Apple product pages | Pinned visual crossfades with the active step, inactive steps stay at full contrast (color, not opacity), each step shows its own visual inline on small screens, `aria-current="step"` |
| Split View | Apple Mail and Finder split views; shadcn resizable | Container-query responsive (stacks with a Back button when its own width is small, not the screen's), keyboard- and pointer-resizable divider with value bounds |
| Masonry Grid | Pinterest-style grids; CSS columns recipes; Magic UI bento | Pure CSS columns (no layout shift, SSR-identical), DOM order equals reading order, per-breakpoint counts, optional reveal that respects reduced motion |
| Scroll Progress | Magic UI scroll progress; Medium reading bar | Spring-smoothed fill that becomes exact under reduced motion, top or bottom, page or panel, decorative (`aria-hidden`) |
| Back To Top | Docs sites; Apple-style floating controls | Progress ring, smooth scroll that jumps under reduced motion, and focus moved to the content afterwards so keyboard users are not stranded |
| Table Of Contents | Docs site TOCs (shadcn, Next.js docs); Tailwind Plus docs | Scroll spy with a sliding marker, heading auto-collection or explicit items, works inside scroll containers, `aria-current="location"`, URL hash updated on click |
| Container Scroll | Aceternity container scroll (idea only); Apple product reveals | 3D frame that flattens as it enters, title that lifts, flat from the start under reduced motion, children stay real interactive content |
| Section Tabs | Stripe/Linear sticky section nav; DaisyUI tabs | Real anchor links driven by the scroll spy, sliding underline or pill, active tab scrolls into view on narrow screens, sticky with a shadow when stuck |
| Command Bar | shadcn command dialog; Linear/Raycast command menus | Nested pages with a breadcrumb and Backspace to go back, search-field-style trigger with the hotkey, footer of key hints, controlled open state and an option to hide the trigger |

Accessibility notes: axe (serious and critical) is clean on every `/preview/*` page in light and dark, and `scripts/a11y-open-states.ts` opens the mega menu, team switcher, command bar, mobile menus and scrolled states before scanning. Demos that scroll inside a box make the scroller a focusable named region, which axe requires. A color-contrast finding on dimmed inactive steps led to the contrast-safe approach in Sticky Scroll. jsdom has no layout, so the scroll hooks are tested with mocked geometry; scroll-linked motion and sticky behavior were checked in the browser.
