# Wave 1 batch 4: dates, data, layout and feedback (completes Wave 1)

Reviewed 2026-09-30. Licenses checked: shadcn/ui (MIT, Copyright (c) 2023 shadcn), React DayPicker (MIT), Embla Carousel (MIT), Recharts (MIT), TanStack Table (MIT), Vaul (MIT), React Hook Form (MIT), input-otp (MIT), react-resizable-panels (MIT), Sonner (MIT). Files that follow a shadcn structure carry the "Based on" header and `meta.source`; `date-picker` is original composition of Ballmac `calendar` and `popover`. No Aceternity, Tailwind Plus, Pro or unlicensed code was copied. Patterns were compared with the [shadcn catalog](https://ui.shadcn.com/docs/components), [DaisyUI](https://daisyui.com/components/) (calendar, carousel, drawer, stat), [ReUI](https://reui.io/components/), [coss UI (Origin UI)](https://coss.com/ui), [Magic UI](https://magicui.design/docs/components), [Motion Primitives](https://motion-primitives.com/), [Aceternity](https://ui.aceternity.com/components) (interaction ideas only), [Cult UI](https://www.cult-ui.com/docs), [Kibo UI](https://www.kibo-ui.com/components), [21st.dev](https://21st.dev/community/components), [Tailwind Plus](https://tailwindcss.com/plus/ui-blocks/application-ui) (demos only) and [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/).

Dependency pins: `react-day-picker@^9`, `@tanstack/react-table@^8` and `react-resizable-panels@^3` (newer majors exist with different APIs; v9/v8/v3 are the widely documented ones), `embla-carousel-react@^8`, `recharts@^3`, `vaul@^1`, `input-otp@^1`, `sonner@^2`, `react-hook-form@^7`.

| Component | Competitor pattern studied | Ballmac improvement |
| --- | --- | --- |
| Calendar | shadcn calendar; DaisyUI Cally; Origin UI calendars | Connected range with rounded ends and quiet middle, today marker dot, styled month/year selects, week numbers, footer slot, all token-driven; outside days keep AA contrast |
| Date Picker | shadcn date picker; Origin UI date inputs; Linear/Notion presets | Presets column, clearable, invalid state, min/max, month and year selects for distant dates, hidden ISO input for native forms, locale-stable trigger text |
| Carousel | shadcn/Embla; DaisyUI carousel; Magic UI marquee | Slide "n of N" labels, dot pagination that widens the active dot, autoplay that pauses on hover/focus and never runs under reduced motion, visible play/pause control, vertical mode, arrow-key handling that ignores form fields |
| Chart | shadcn chart; Tremor; Recharts defaults | `<figure>` with accessible name and a screen-reader summary, keyboard navigation via `accessibilityLayer`, token series colors per theme, indicator styles, locale-fixed number formatting |
| Data Table | shadcn data table; TanStack examples; Kibo table | One component instead of a recipe: sort, search, column menu, selection with indeterminate header, pagination, loading rows, empty state, polite result count, focusable named scroll region |
| Drawer | shadcn/Vaul; DaisyUI drawer; Apple sheets | Four directions, grab handle only where it applies, focusable scrolling body that stays draggable-safe, safe-area footer, reduced-motion transitions |
| Form | shadcn form; React Hook Form docs; Conform | `FormField` renders label, control, description and error with ids, `aria-invalid`, `aria-describedby` and focus-on-error wired automatically, plus `FormSubmit` with a pending spinner; no per-field context boilerplate |
| Input OTP | shadcn input-otp; Origin UI OTP; Stripe/Apple code fields | Single real input under the slots (paste, autofill, screen readers), grouped slots with a separator, pop-in digits and caret that stop for reduced motion, invalid state driven by `aria-invalid` |
| Resizable | shadcn resizable; VS Code panels; Apple split views | Labelled separators, 12px hit area, grip that appears on hover/focus/drag, visible keyboard focus ring, collapsible panels, nested groups in the demo |
| Sidebar | shadcn sidebar; DaisyUI drawer/menu; Linear/Vercel navigation | Trimmed to the parts most apps use: icon-rail, offcanvas and floating/inset variants, links without `asChild`, tooltips only while collapsed, labelled nav landmark, mobile sheet with a named dialog, Cmd/Ctrl+B |
| Toast | shadcn Sonner; Radix Toast; Magic UI animated list | Theme-token styling without a theme provider (follows the site's light/dark switch), status icons, accessible action and cancel buttons, `toasterId` for multiple regions |

Accessibility notes: axe (serious and critical) is clean on every `/preview/*` page in light and dark, and `scripts/a11y-open-states.ts` opens the popovers, drawers, menus, toasts and form errors before scanning. jsdom has no layout, so tests for `resizable` and `drawer` check semantics and keyboard activation; drag distances and sizes were checked in the browser.
