# Wave 9, batch B: motion patterns, progress and cards

Reviewed 2026-10-01. All 12 components are original Ballmac code built on Motion, Radix Dialog and the Ballmac `dialog`. No code was copied from Aceternity, Tailwind Plus, any Pro kit or anything unlicensed, and none were adapted from Magic UI, Motion Primitives or NumberFlow source, so none carry a "Based on" header; only the ideas overlap. Patterns were compared with [Magic UI](https://magicui.design/docs/components), [Motion Primitives](https://motion-primitives.com/), [NumberFlow](https://number-flow.barvian.me/), [Aceternity](https://ui.aceternity.com/components) (visual ideas only), [Vaul](https://vaul.emilkowal.ski/), [Cult UI](https://www.cult-ui.com/docs), [Kibo UI](https://www.kibo-ui.com/components), [21st.dev](https://21st.dev/community/components), Apple Fitness rings and Health gauges, Stripe and Linear pricing pages, and Vimeo and YouTube embeds.

Where a component overlaps something already in the registry, the difference is deliberate: `circular-progress` draws several rings or a 270 degree gauge (`progress-ring` is a single ring), `avatar-circles` spreads and shows tooltips and presence (`avatar-stack` is a plain compact row), `magic-card` lights a two-color border (`spotlight-card` is one soft glow), `neon-card` is a steady neon frame (`glow-border` rotates), `animated-number-flow` rolls digits on any change (`number-ticker` counts up once on scroll), `animated-list` is a live feed (`stagger-list` is an entrance and reorder), and `spring-drawer` adds snap points on Radix (`drawer` wraps Vaul).

| Component | Competitor pattern studied | Ballmac improvement |
| --- | --- | --- |
| Animated List | Magic UI Animated List | Keyed items that spring in at the top while the rest glide down, leave animations, an item cap, an optional fading tail, and an opt-in polite announcement of additions only |
| Stagger List | Motion Primitives and Framer staggered lists | Real `ul`/`ol` markup, five entrance directions, and items that glide to their places when filtered, sorted, added or removed |
| In View | Motion Primitives In View | `data-in-view` for pure-CSS styling, a render-function child and a change callback, with five built-in entrances and an `amount` and `margin` control |
| Animated Number Flow | NumberFlow, Magic UI Number Ticker | Digits roll like an odometer on any change, keyed by place value so columns stay aligned as digits appear, full `Intl` formatting with a fixed default locale, masked edges, and the formatted text for screen readers |
| Circular Progress | Apple Fitness rings, shadcn chart radial | Concentric rings or a 270 degree gauge, animated fills, a legend with values, a center slot, and an accessible name that lists every ring |
| Avatar Circles | Magic UI Avatar Circles | Faces spread on hover, lift individually with a name and role tooltip, show presence in the accessible name, fall back to initials, and end in a "+N" that can be a button |
| Magic Card | Magic UI Magic Card | A two-color light along the border plus a faint inner glow, driven by CSS variables so moving never re-renders, a centered light on keyboard focus, and theme tokens for color |
| Neon Card | Aceternity and Magic UI glow cards (look only) | A steady two-color neon frame with outer light and inner glow, tunable thickness, intensity and radius, and an opt-in warm-up flicker that never plays under reduced motion |
| Glare Hover | Aceternity and React Bits glare cards (look only) | Wraps any content, sweeps once per hover or focus with pure CSS transitions, resets instantly on leave, in a light or dark tone |
| Lens | Magic UI Lens | Magnifies any content, not just images, moves with the arrow keys when focused, hides on Escape, ignores touch so scrolling still works, and keeps the magnified copy inert and out of the accessibility tree |
| Spring Drawer | Vaul, shadcn Drawer | Snap points with spring settling and flick-to-dismiss on Radix Dialog (focus trap, scroll lock), a keyboard-operable handle slider, and left and right variants |
| Video Dialog | Magic UI Hero Video Dialog | A thumbnail button that reads "Play video: Title", a player created only on open and removed on close, support for video files, embed URLs and YouTube from the privacy-friendly domain |

Accessibility notes: axe (serious and critical) is clean on every `/preview/*` page in light and dark, and `scripts/a11y-open-states.ts` scans batch B in its interacted states (a filtered list, yearly prices, an open drawer, a hovered avatar and card, a magnifier over an image, an opened video dialog) after animations finish. Findings that shaped the final code: `aria-valuetext` is not allowed on a group, so multi-ring progress is an image whose name lists every ring; initials in saturated chart colors failed contrast, so avatars use a pale tint of the color with foreground text; and screen reader names built from a hidden prefix lost their trailing space, so the prefix and a real space are now separate. jsdom has no layout, so the lens test gives elements a size.
