# Wave 9, batch C: backgrounds and heavier effects

Reviewed 2026-10-01. Ten of the eleven components are original Ballmac code built on Motion, SVG and canvas. `dotted-map` is the exception: its land mask is derived from the world texture inside [cobe](https://github.com/shuding/cobe) (MIT, Copyright (c) 2021 Shu Ding), so it carries a "Based on" header, `meta.source`, and an entry in `THIRD_PARTY_NOTICES.md`; the rendering itself is new. No code was copied from Aceternity, Tailwind Plus, any Pro kit or anything unlicensed, and none of the others were adapted from Magic UI source. Patterns were compared with [Magic UI](https://magicui.design/docs/components), [Aceternity](https://ui.aceternity.com/components) (visual ideas only), [Motion Primitives](https://motion-primitives.com/), [React Bits](https://reactbits.dev/), [Cult UI](https://www.cult-ui.com/docs), [21st.dev](https://21st.dev/community/components), Codrops effects, the dotted-map library, Apple and Linear marketing pages, and Awwwards-style portfolios.

Where something overlaps the registry, the difference is deliberate: `grid-pattern` is a line grid (`dot-pattern` is dots), `interactive-grid` reacts to the pointer on a canvas (`animated-grid` and `flickering-grid` are random), `warp-background` is a tunnel (`particles` drifts), `dotted-map` is a flat SVG map (`globe` is a 3D WebGL globe), and `scroll-velocity` reacts to scroll (`marquee` runs at a constant speed).

| Component | Competitor pattern studied | Ballmac improvement |
| --- | --- | --- |
| Retro Grid | Magic UI Retro Grid | Perspective floor with a fade at the horizon and a tinted glow, tone and tilt controls, and a still floor under reduced motion |
| Grid Pattern | Magic UI Grid Pattern | One SVG pattern with dashed lines, filled cells, random cells that glow (chosen after mount), four edge fades, all in border and foreground tokens |
| Interactive Grid | Magic UI Interactive Grid Pattern | Canvas cells that glow and fade out in a trail; it listens on its parent so content above never blocks it, and its frame loop stops when idle |
| Warp Background | Magic UI Warp Background | A canvas hyperspace tunnel in theme colors with a vignette that keeps text readable, parallax toward the pointer, pausing off screen, and a still frame for reduced motion |
| Light Rays | Magic UI Light Rays | Deterministic swaying beams from a theme token (server and browser match), adjustable count, spread and intensity |
| Noise Texture | Common CSS grain overlays | Inline SVG turbulence (no image file), blend modes, tile size and fineness, optional shimmer that is off for reduced motion |
| Progressive Blur | Magic UI Progressive Blur | Stacked backdrop-filter layers that ramp toward any of four edges, a server component with no JavaScript, and pointer events pass through |
| Scroll Velocity | Magic UI Scroll Based Velocity | Reverses and speeds up with scroll for the page or any scroll container; repeats are hidden and inert; reduced motion gives one scrollable row |
| Smooth Cursor | Magic UI Smooth Cursor | Scoped to an area instead of the whole page, ignores touch, leaves text fields on the normal caret, supports `data-cursor-label` and custom graphics |
| Icon Cloud | Magic UI Icon Cloud (canvas) | Real list markup with any children (links and buttons stay focusable and clickable), drag only starts after a few pixels, spin pauses under the pointer and on focus |
| Dotted Map | Magic UI Dotted Map, the dotted-map library | A built-in land mask (no dependency, nothing fetched), pulsing markers, flowing routes, optional labels, and a text summary for screen readers |

Accessibility notes: axe (serious and critical) is clean on every `/preview/*` page in light and dark, and `scripts/a11y-open-states.ts` scans batch C after moving the pointer, scrolling the demo scrollers and focusing links. One finding shaped the final code: the icon cloud's far-side items were faded too far for text contrast, so depth now only dims them to 62 percent. Also fixed: the dotted map's marker pulse used CSS transforms in SVG units and landed in the wrong place, so it now animates the circle's radius. jsdom has no canvas or layout, so canvas tests use a stub context and layout tests give elements a size.
