# Wave 8: developer components

Reviewed 2026-10-01. All 10 components, and the shared `highlight` tokenizer they use, are original Ballmac code built on primitives already in the registry (Radix via `radix-ui`, Motion, and the Ballmac `dialog`, `kbd`, `switch` and new `copy-button`). No code was copied from Aceternity, Tailwind Plus, any Pro kit or anything unlicensed, so none carry a "Based on" header. Patterns were compared with the [shadcn catalog](https://ui.shadcn.com/docs/components), [Magic UI](https://magicui.design/docs/components) (copy and terminal pieces), [Kibo UI](https://www.kibo-ui.com/components) (code block, snippet, status and git components), [Mintlify](https://mintlify.com/) and [Stripe](https://docs.stripe.com/api) API reference layouts, [Vercel](https://vercel.com/docs) environment variable and log screens, [Better Stack](https://betterstack.com/) and [Statuspage](https://www.atlassian.com/software/statuspage) status pages, the GitHub and Stripe webhook delivery screens, the GitHub and GitKraken commit graphs, [Linear](https://linear.app/) and [Raycast](https://www.raycast.com/) shortcut sheets, and npm package pages.

Shared design decisions: nothing is fetched (package facts, favicons and statuses are passed in); status is always an icon plus a word (and bar height for history), never color alone; the one tokenizer (`highlight`) colors code by mixing chart tokens into the foreground, so contrast holds in light and dark and the palette follows the theme; every date and time are rendered from ISO strings in UTC with a fixed locale, so server and browser agree; and every animation has a reduced-motion path.

| Component | Competitor pattern studied | Ballmac improvement |
| --- | --- | --- |
| Copy Button | Magic UI and shadcn copy buttons, GitHub copy icon | Spring-morphing check, optional label, `getValue` for text read at click time, a `document.execCommand` fallback for blocked clipboards, an explicit "Copy failed" state, and a polite announcement |
| Snippet Tabs | Stripe and Mintlify language tabs, shadcn code tabs | Language remembered across the whole page (and browser tabs) through a shared store, `{{variables}}` filled with the viewer's own values in both the view and the copy, built-in highlighting with no dependency, and keyboard tabs with named regions |
| Status Badge Row | Better Stack and Statuspage uptime bars | Overall banner that reports the worst state, per-service chips with icon and word, 90-day history that is a keyboard slider with spoken day values, and bar height as a second cue so color is not the only signal |
| Package Badge | npm package pages, shields.io badges | A card with weekly downloads and sparkline, size, license, types and formats, a copyable install command for the chosen package manager, plus a compact pill for READMEs; nothing is fetched |
| Keyboard Shortcuts | Linear and Raycast shortcut sheets, GitHub "?" help | Searchable by action or key, `Mod` becomes Command or Ctrl for the viewer's platform after hydration, key sequences ("G then I"), spoken key names, and a dialog that opens with "?" but never while typing |
| API Endpoint | Stripe, Mintlify and Redoc operation cards | Method chip and path with highlighted `{params}`, grouped parameter lists with required and default markers, request and response tabs with highlighted examples and per-block copy, collapsible, and copy of the full URL |
| Env Editor | Vercel and Netlify environment variable screens | Masked values with per-row and global reveal, name validation and duplicate detection linked with `aria-describedby`, paste a whole `.env` into any name field or a paste box to import, Copy as `.env`, and focus management on add and remove |
| Log Stream | Vercel and Datadog log viewers, Dozzle | Level filters with counts, search with highlighted matches, wrap, pause with a "N new lines" counter, tail-following that stops when you scroll up, UTC times, and a labelled scrollable `role=log` that does not chatter at screen readers |
| Webhook Card | Stripe and GitHub webhook delivery pages | Enable switch, health computed from recent deliveries (Active, Failing, Disabled), masked signing secret, event chips with overflow count, expandable deliveries with request and response bodies, and Redeliver |
| Git Graph | GitHub network graph, GitKraken, `git log --graph` | Lane assignment computed from parents, curved branch and merge lines, branch and tag labels, authors and dates, selection, and a real listbox with arrow, Home, End and Enter handling |

Accessibility notes: axe (serious and critical) is clean on every `/preview/*` page in light and dark, and `scripts/a11y-open-states.ts` scans Wave 8 in its interacted states (copied, Python tab, history cursor, open dialog, response tab, revealed env values, filtered logs, expanded deliveries, moved commit cursor). Findings that shaped the final code: a definition list that held a button (changed to a plain list), a 9 px label on a tinted chip failed contrast (changed to the foreground token), commit rows overflowed their fixed height on phones when branch chips wrapped (chips move under the message on narrow containers), and the dialog's built-in `sm:p-6` needed an `sm:p-0` override to make a full-bleed header.
