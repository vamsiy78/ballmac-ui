# Wave 7: AI interfaces

Reviewed 2026-09-30. All 12 components are original Ballmac compositions over primitives already in the registry (Radix via `radix-ui`, cmdk through the Ballmac `command`, Motion, and the Ballmac `popover` and `hover-card`). No code was copied from Aceternity, Tailwind Plus, any Pro kit or anything unlicensed, so none carry a "Based on" header. Patterns were compared with the [shadcn catalog](https://ui.shadcn.com/docs/components), [Vercel AI Elements](https://ai-sdk.dev/elements) and [assistant-ui](https://www.assistant-ui.com/) (structure and props ideas only), [Kibo UI](https://www.kibo-ui.com/components), [Magic UI](https://magicui.design/docs/components), [Motion Primitives](https://motion-primitives.com/), [Cult UI](https://www.cult-ui.com/docs), [21st.dev](https://21st.dev/community/components), [Aceternity](https://ui.aceternity.com/components) (visual ideas only), [DaisyUI](https://daisyui.com/components/), and the behavior of real assistants: ChatGPT and Claude model pickers, Perplexity citations and source lists, Claude artifacts, Cursor and Claude Code approval prompts, and voice modes.

Shared design decisions: state is never color alone (risk, warning and status always carry an icon and words); anything that cycles or chatters (thinking phrases, timers, waveforms) is hidden from screen readers and replaced by one calm announcement; nothing is fetched from third parties (favicons are drawn as monograms unless a URL is passed); every animation has a reduced-motion path; and each component ships the states a real product needs (loading, streaming, failed, locked, resolved).

| Component | Competitor pattern studied | Ballmac improvement |
| --- | --- | --- |
| Model Picker | shadcn combobox, ChatGPT and Claude model menus, AI Elements `model-selector` | Grouped and searchable like a command menu, with a detail pane that follows the highlighted row (context window, cost, abilities in words), locked plans that explain themselves, and a hidden search input so arrow keys and type-ahead work even without a visible search box |
| Suggestion Chips | ChatGPT starter cards, AI Elements `suggestion`, Magic UI chip rows | Three layouts (wrapping pills, swipeable row with faded edges, cards with descriptions), loading placeholders, a refresh button that turns, and a named group for assistive tech |
| Citation | Perplexity and ChatGPT inline source chips, AI Elements `inline-citation` | Real links (touch users go straight to the source), hover and focus preview card with excerpt, pager for several sources behind one claim, number or site-pill style, and monogram icons instead of third-party favicon requests |
| Sources List | Perplexity "Sources", Claude search results, AI Elements `sources` | Stacked site icons on the header, list or card grid, show-all, `highlight` and stable row ids so hovering a citation can light up its row |
| Chat Attachment | ChatGPT and Claude composer file chips, AI Elements `attachments` | Chip and tile layouts, type detection from MIME or extension, upload progress with `role=progressbar`, failed state with the reason and Retry, no nested buttons (open is an overlay sibling of remove), and animated removal |
| Voice Input | ChatGPT dictation bar, WhatsApp voice notes, Vercel AI SDK voice examples | Round button or expanding recorder with a scrolling waveform sampled on a steady beat, timer, discard and send, Escape to discard, focus returns to the mic, and an exported `useMicrophoneLevel` hook that reads the real input |
| AI Orb | ChatGPT voice orb, Magic UI and Aceternity glow and aurora effects | A glass orb from theme chart colors (so it follows any theme), four states that change drift speed and breathing, swells with a live `level`, static under reduced motion, and named for screen readers (or hidden with `label={null}`) |
| Artifact Panel | Claude artifacts, ChatGPT canvas, v0 preview panes | Preview and Code tabs with arrow-key switching, version stepping with polite announcements, copy and download, a streaming state that writes into the code view and disables actions, and your own preview slot |
| Thinking Indicator | ChatGPT typing dots, Claude shimmer text, AI Elements `loader` | Four animations, phrases that take turns (visual only) with one announcement for screen readers, optional timer, and calm reduced-motion fallbacks |
| Token Meter | Cursor and Claude Code context gauges, OpenAI usage pages | Stacked system, history and attachment segments with a hatched reserved reply area, warn and full states in words, cost line, a compact-action slot, and a composer pill that opens the same view in a popover |
| Agent Plan | Cursor and Devin task lists, AI Elements `plan` and `task` | Timeline with five explicit states, nested substeps, expandable output, leaf-step progress bar, retry on failure, and a polite status line that names the current step |
| Approval Card | Claude Code and Cursor permission prompts, AI Elements `confirmation` | Risk level in words and icon, the exact action in a labelled scrollable region, Approve, Deny and Always allow, a timeout countdown, and a recorded decision that receives focus so keyboard users do not lose their place |

Accessibility notes: axe (serious and critical) is clean on every `/preview/*` page in light and dark, and `scripts/a11y-open-states.ts` scans Wave 7 in its interacted states (open model list with the highlight moved, focused citation card, removed attachment, opened token popover, approved card, recording bar, Code tab). Findings that shaped the final code: the timer text and a locked option with reduced opacity failed color contrast (fixed by using the full muted token and a lock chip instead of fading), and the model list needed an always-present (sometimes visually hidden) search input so cmdk receives keyboard events. Accessible names were made robust by splitting status words into their own element followed by a real space, because trailing whitespace inside an element is dropped by some name algorithms. jsdom cannot finish exit animations, so the label cross-fade test turns Motion's animations off.
