# Templates batch A: product marketing

Reviewed 2026-10-01. Four multi-page templates, each with its own palette, font pairing and signature interaction: Orbit (AI agent platform), Relay (developer API), Ledger (Mac app) and Northwind (B2B SaaS). All code is original Ballmac work assembled from components and blocks already in the registry; no code was copied from Aceternity, Tailwind Plus (Salient, Spotlight, Radiant, Studio), Magic UI Pro, Cruip, shadcnblocks or any paid kit, so none carry a "Based on" header. Structure and ambition were compared with those kits, [shadcn blocks](https://ui.shadcn.com/blocks), [Origin UI](https://originui.com), [21st.dev](https://21st.dev/community/components), and the live sites of Linear, Vercel, Stripe, Raycast, Resend, Svix, Ramp and Mercury.

What most kits do: one long landing page, one shared look, screenshots instead of product, copy that could belong to any company. What these do instead:

| Template | Look | Signature interaction | Pages | What is better than the usual |
| --- | --- | --- | --- | --- |
| Orbit | Dark-first ink with violet light, Instrument Sans and JetBrains Mono | A scripted agent run that plays when it scrolls into view: plan, tool calls, an approval and a reply, with a live trace, elapsed time, tokens and cost, and a Replay button | Home, Pricing (usage calculator with stepped overage), Changelog (filterable), Sign in | The hero shows the product working instead of a screenshot; reduced motion jumps to the finished run; every step has a text state for assistive technology |
| Relay | Warm paper and black ink with one orange signal, Hanken Grotesk and IBM Plex Mono, ruled grid; full dark mode | A send console and language-synced code samples: pick Python once and every sample on every page follows | Home, Docs (sidebar, quickstart, API reference, on-page contents), Pricing (per-million estimator), Status (90-day uptime bars) | The life of an event shows retries as a timeline; docs and marketing share one language switch; the status page gives each chart a text summary |
| Ledger | Apple-calm cool white, system UI with Inter fallback and one italic serif word per heading; follows the system dark mode | The real interactive Mac desktop from `showcase-1` as the hero, then the menu-bar tour, device lineup and the buy-once or subscribe cost chart | Home, Download, Pricing, What's new, Support (live-filtered help) | Built from the Mac blocks rather than mock images; the download page chooses Apple silicon or Intel and publishes checksums |
| Northwind | Cream paper, forest ink and terracotta, Fraunces and Figtree; deep green in dark mode | A product tour: a mock dashboard with numbered pins tied to a radio list of steps | Home, Pricing, Customers (case study), About, Contact (validated demo form) | Editorial voice instead of a tech look; the tour is fully operable from the step list (pins are a pointer-only duplicate); the form focuses the first problem and confirms in a live region |

Shared decisions: every palette is a scoped block of standard Ballmac tokens (a `<style>` string for light and dark, or inline variables for Orbit's always-dark theme), so blocks dropped into a template follow its look with no overrides; fonts load through `next/font/google` in one `*-fonts.ts` file per template; pages take an `hrefs` prop so the previews navigate between sibling previews while installed routes use real paths; fixed `en-US` formatting and no randomness in render.

Accessibility notes: axe (serious and critical) is clean on every page in light and dark, and `scripts/a11y-open-states.ts` scans interacted states (a finished agent run, a changed billing period and slider, the sent sign-in state, a console response, a switched code language, a switched tour step, validation errors). Findings that shaped the final code: numbered tour pins inside an `aria-hidden` mock were focusable, so they became a hidden, non-focusable duplicate of the step list; the contact form tried to focus an invalid field before React had rendered `aria-invalid`; the install snippet and a diagram scroller on the site were not keyboard reachable (now focusable); and the `@relay/sdk` import inside sample strings tripped the dependency scanner (the package name is a variable).
