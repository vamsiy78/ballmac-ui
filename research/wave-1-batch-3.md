# Wave 1 batch 3: menus, overlays, and form structure

Reviewed 2026-09-30. Licenses checked: shadcn/ui (MIT, Copyright (c) 2023 shadcn), Radix Primitives (MIT) and cmdk (MIT, Copyright (c) 2022 Dip). Each file that follows a shadcn structure carries the "Based on" header and `meta.source`; `combobox` is original composition of Ballmac `popover` and `command`. No Aceternity, Tailwind Plus, Pro or unlicensed code was copied. Patterns were compared with the [shadcn catalog](https://ui.shadcn.com/docs/components), [DaisyUI](https://daisyui.com/components/), [ReUI](https://reui.io/components/), [coss UI (Origin UI)](https://coss.com/ui), [Magic UI](https://magicui.design/docs/components), [Motion Primitives](https://motion-primitives.com/), [Aceternity](https://ui.aceternity.com/components) (looked at for interaction ideas only), [Cult UI](https://www.cult-ui.com/docs), [Kibo UI](https://www.kibo-ui.com/components), [21st.dev](https://21st.dev/community/components), [Tailwind Plus](https://tailwindcss.com/plus/ui-blocks/application-ui) (demos only) and [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/menus). Magic UI and Aceternity ship few form and menu primitives, so their contribution here is the demo bar, not the API.

| Component | Competitor pattern studied | Ballmac improvement |
| --- | --- | --- |
| Dropdown Menu | shadcn/Radix dropdown; DaisyUI dropdown; ReUI menus | Destructive and inset item props instead of raw variants, `aria-hidden` shortcut slot with guidance to pair `aria-keyshortcuts`, viewport-aware max height and transform origin, reduced-motion-safe entry, and an account-menu demo that opens with a submenu and checked item |
| Context Menu | shadcn/Radix context menu; Apple HIG contextual menus | Same item API as the dropdown so menus are interchangeable; demo makes the trigger keyboard reachable (`tabIndex`, label, Shift+F10) which the shadcn demo does not |
| Menubar | shadcn/Radix menubar; DaisyUI menu; Apple HIG menu bar | Bar and panel styled to match the dropdown, default-open menu for the demo, roving focus tested (Left/Right between triggers, Down to open) |
| Sheet | shadcn sheet; vaul drawers; DaisyUI drawer | Four edges from one cva, grab handle on bottom sheets, `SheetBody` that is focusable and scrolls, footer safe-area padding, width capped so the page stays visible at 390 px |
| Slider | shadcn/Radix slider; DaisyUI range; Origin UI slider with tooltip | Per-thumb names (`thumbLabels`) so range sliders have accessible thumbs, `aria-label`/`labelledby` forwarded to the thumb, live value bubble on hover, focus and drag, `aria-valuetext` from `formatValue`, vertical layout |
| Table | shadcn table; DaisyUI table; Kibo table | Scroll region is focusable and named (fixes axe scrollable-region-focusable), sticky header, striping, three densities, `aria-sort` with icon on `TableHead`, `selected` rows with `aria-selected`, numeric columns |
| Item | shadcn item; DaisyUI list; ReUI list rows | Compact size, hover state only when the item is a link or button, media variants (icon/image), no forced list roles so link rows stay valid |
| Field | shadcn field; DaisyUI fieldset/label; React Aria fields | `useFieldControl()` generates and links id, `aria-describedby`, `aria-invalid` and `disabled`, so the label, description and error are wired without manual ids; deduplicated error list with `role="alert"` |
| Input Group | shadcn input group; DaisyUI join/input with icons; Origin UI addons | Block-start/end addons for textarea composers, click-to-focus addons that leave buttons alone, invalid and disabled states drawn by the group, xs/sm/icon button sizes |
| Navigation Menu | shadcn navigation menu; Aceternity navbar (ideas only); Tailwind Plus flyouts | Shared animated viewport that resizes with content, `viewport={false}` option, `topLevel` links styled like triggers (works from server components), chevron and motion respect reduced motion |
| Command | shadcn command / cmdk; Spotlight-style launchers | Page-safe scrolling (cmdk `scrollIntoView` no longer scrolls the page), hotkey dialog with hidden title and description, item description and selected check, loading row, separators hidden from assistive tech (fixes axe aria-required-children in listbox) |
| Combobox | shadcn combobox (popover + command); Origin UI combobox; DaisyUI select with search | One `options` prop with groups, descriptions, icons and keywords; clearable; invalid; native form value through `name`; trigger width-matched popup; focus returns to the trigger |

Accessibility notes: Radix supplies focus management, typeahead, roving focus and Escape handling for the menu family, sheet and navigation menu. Axe reports `aria-hidden-focus` for Radix modal menus (page behind is `aria-hidden` while focus is trapped in the menu) and for `NavigationMenu`'s own hidden focus proxy. These are upstream patterns, so previews keep those overlays closed (or non-modal, for the default-open dropdown demo) and `scripts/a11y-open-states.ts` opens them and reports the two findings separately from any other violation.
