# Blocks batch A: marketing sections

Reviewed 2026-10-01. All thirteen blocks are original Ballmac code assembled from components already in the registry (Motion, Radix through `radix-ui`, lucide-react and our own button, badge, accordion, tabs, segmented control, mega menu, sheet, install tabs, number ticker, sparkline, browser frame). No code was copied from Aceternity, Tailwind Plus, shadcnblocks or any Pro kit, so none carry a "Based on" header. Layouts and interaction patterns were compared with the [shadcn blocks](https://ui.shadcn.com/blocks), [Magic UI](https://magicui.design) templates and sections, [Origin UI](https://originui.com), [ReUI](https://reui.io), [DaisyUI](https://daisyui.com) components and [21st.dev](https://21st.dev/community/components) community sections, plus the public marketing pages of well-known SaaS products for pacing and hierarchy.

Shared decisions: every block takes its copy and data through typed, documented props with realistic Acme content; sample "screens" are drawn with theme tokens (no screenshots, no external images), so they follow light and dark and any theme; decorative pictures are `aria-hidden` and the text carries the meaning; each block collapses to a single clean column at 390 px; motion stops for reduced motion; no random values or `Date.now()` in render, and currency uses a fixed `en-US` format.

| Block | Competitor pattern studied | Ballmac improvement |
| --- | --- | --- |
| Hero 6 | Gradient-mesh heroes with static floating cards | Slowly drifting colour mesh from the chart tokens, cards that bob and follow the pointer with per-card depth (springs, off for touch and reduced motion), gradient headline words, cards stack under the buttons below `xl` and become a replaceable slot (`Hero6Float`) |
| Hero 7 | Scroll-tilt product screenshot heroes | Pure-token sample dashboard (KPI cards, area chart, invoices) that needs no assets, scroll-linked lean and settle with the shadow and glow, `screenshot` or any `screen` node scaled from 1180 px, tilt is a prop |
| Features 5 | Sticky scroll-story sections | Active step found by an intersection band, progress rail, crossfading sticky visual with blur, each step carries its own picture on phones, visuals are slots |
| Features 6 | Tabbed feature panels | Sliding pill indicator, one panel at a time with check-listed points and a link, tabs scroll sideways on phones, proper tab semantics with arrow keys |
| Pricing 2 | Three-card pricing with a toggle | Rolling digits on the price, "billed" total line, status announcement of the interval, controlled or uncontrolled, string prices ("Custom"), lifted featured plan with border beam, optional enterprise strip |
| Pricing 3 | Feature comparison tables | Sticky header with offset prop, collapsible groups (real buttons with `aria-expanded`), highlighted column, text-labelled check and dash cells, phone layout is a plan switcher with grouped lists instead of a sideways-scrolling table |
| Stats 1 | Metric grids with big numbers | Count-up on scroll with decimals, delta with arrow, labelled trend sparkline, definition-list semantics, hairline grid |
| Testimonials 2 | Single featured quote carousels | Real tab semantics with arrow keys, Home and End, optional autoplay that pauses on hover and focus and never runs with reduced motion, highlighted result badge, controlled index |
| Team 1 | Portrait grids with social links | Bio reveals on hover and on keyboard focus, shown inline on phones (no hover dependency), initials tiles when there is no photo, labelled link icons |
| FAQ 2 | Accordion FAQs | Live search with highlighted matches (regex-safe), topic filters with counts and `aria-pressed`, polite result count, empty state with reset, support prompt |
| CTA 3 | Command-line call to action | Install tabs for npm, pnpm, yarn and bun with a copy button, optional remembered package manager, explicit per-manager commands |
| Footer 2 | Giant-wordmark footers | Wordmark sized from its length with a fading gradient, live status pill, labelled icon links, hidden from assistive technology |
| Header 2 | Mega-menu headers | Built on our mega menu (arrow keys, escape, focus return) with a slide-in sheet on phones that closes when a link is chosen |

Accessibility notes: axe (serious and critical) is clean on every `/preview/*` page in light and dark, and `scripts/a11y-open-states.ts` scans the interacted states (open mega menu and mobile sheet, monthly pricing, collapsed comparison group, search results and empty state, switched tabs, another quote, another package manager, focused team link). Findings that shaped the final code: coloured initials on chart-colour tiles failed contrast in one theme (they are now tinted tiles with foreground text), green delta text failed in light mode (the arrow carries the colour, the number uses the foreground), and two grid layouts overflowed at 390 px until their columns got `min-w-0`.
