# Blocks batch D: application screens

Reviewed 2026-10-01. All twelve blocks are original Ballmac code assembled from components already in the registry (chart on Recharts, sidebar-free layout built with our dropdown menu, command menu, sheet, dialog, alert dialog, popover, calendar, select, switch, toggle group, segmented control, search field, avatar, badge, prompt input, artifact panel and streaming text). No code was copied from Aceternity, Tailwind Plus, shadcnblocks or any Pro kit, so none carry a "Based on" header. Layouts and behavior were compared with the [shadcn blocks](https://ui.shadcn.com/blocks) dashboard, sidebar, mail and calendar examples, [Origin UI](https://originui.com), [ReUI](https://reui.io), [21st.dev](https://21st.dev/community/components) application sections, and the real settings, billing, inbox, board and scheduling screens of widely used products. Charts follow the dataviz rules: one axis, thin marks, a legend whenever there are two series, recessive grid, direct text for values, a text summary on every figure, and chart tokens that follow the theme.

Shared decisions: every screen works with no data passed in (deterministic demo data, fixed `en-US` formatting, ISO dates formatted in UTC, `today` and `now` passed as props where the page depends on the current day), takes your data through typed props and reports changes through callbacks that may throw; every list, chip row and filter is real buttons with `aria-pressed` and a polite result count; destructive actions ask first; status is never colour alone; every screen collapses to one clean column at 390 px; frames (`app-shell-1`, `mail-1`, `calendar-1`, `ai-chat-2`) take a `height` and scroll inside it.

| --- | --- | --- |

Accessibility notes: axe (serious and critical) is clean on every `/preview/*` page in light and dark, and `scripts/a11y-open-states.ts` scans the interacted states (the open command menu, changed ranges, a dirty settings form and a failed save, toggled notifications, invalid invitations, the card dialog with errors, a picked-up card, an open event popover, a streamed reply). Findings that shaped the final code: the shared Calendar painted today's date white on a pale tint when it was also the selected day (the today styling looked for the selected attribute on the wrong element; fixed in the Calendar component, which also improves the date pickers), the command menu already owns the ⌘K shortcut so the block must not add a second one, event times lost contrast on tinted event backgrounds, the artifact panel hid the chat on phones by default, and the card list on the kanban board needed padding and flexible columns to fill wide screens.
