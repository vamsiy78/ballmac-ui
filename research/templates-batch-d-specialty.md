# Templates batch D: specialty

Reviewed 2026-10-01. Four specialty templates, each with its own art direction: Tern (documentation), Northlight Summit (a conference), Kiln & Co (an online store, `template-goods`) and Pocket (a mobile money app). All code is original Ballmac work assembled from components already in the registry; nothing was copied from Aceternity, Tailwind Plus (Syntax, Transmit, Salient, Commit, Spotlight), Magic UI Pro, shadcnblocks or any paid kit, so none carry a "Based on" header. They were compared with those kits, [shadcn blocks](https://ui.shadcn.com/blocks), [Magic UI](https://magicui.design) templates, [Nextra](https://nextra.site), [Docusaurus](https://docusaurus.io), [Mintlify](https://mintlify.com) and Stripe docs for documentation; Config, Figma Config and Smashing Conference sites for events; Shopify's Dawn and Horizon themes and Aesop and Hay for stores; and the sites of Monzo, Revolut, Cash App and Wise for the money app.

What most template kits do: a docs site that is a sidebar and a screenshot, an event site that is a hero with a date, a shop that is a grid with no cart, and an app landing page with a static phone image. What these do instead:

| Template | Look | Signature interaction | Pages | What is better than the usual |
| --- | --- | --- | --- | --- |
| Tern docs | Cool mist paper, deep teal ink, Newsreader headings with Instrument Sans and JetBrains Mono | ⌘K search over guides, endpoints and releases; language tabs that follow you across every page | Home, Guide, API reference, Search, Changelog | A guide in numbered steps with copyable keys, callouts and a feedback box that asks what was missing; endpoint cards that filter by method or text; a search page with highlighted matches and suggestions; a changelog with tag filters and a version rail |
| Northlight Summit | A sunrise ridgeline over indigo, Unbounded with Figtree | A live countdown, a schedule you star into an agenda with clash warnings | Home, Schedule, Speakers, Tickets, Venue | The hero is a painted scene, not a photo; an agenda that tells you which talks overlap; speaker bios in a dialog with the time of the talk; tickets with a live total, group discount and promo code; a venue map and arrival options |
| Kiln & Co | Oat paper, warm brown ink and five glazes, Fraunces with Hanken Grotesk | A bag that persists across pages, a glaze picker that recolours the product | Home, Shop, Product, Bag, Checkout | Every product is drawn in CSS (mug, bowl, vase, plate, pitcher, cup) in five glazes and four views, so there are no stock photos; filters with removable chips; a free-shipping meter; a validated checkout that formats the card as you type |
| Pocket | Mint paper, navy ink, cobalt and one loud lime, Gabarito | A working app in a phone (tabs, freeze the card), plus live feature demos | Home, Features, Pricing, Security, Download | The features page is five working demos (freeze a card, round-up calculator, bill splitting, exchange rate, spending bars); pricing with a yearly switch and a real comparison table; a lost-phone timeline instead of a badge wall; a text-me-the-link form |

Shared decisions: each palette is a scoped block of standard Ballmac tokens in a `<style>` string for light and dark, also applied through `body:has(.template-theme)` so portaled UI (the docs search, the bag drawer, the speaker dialog) inherits it. Pages take an `hrefs` prop so previews navigate between sibling previews; dynamic routes (the product page) are hand-written, and preview links pass the product as `?p=`. The bag is a small `useSyncExternalStore` store kept in `sessionStorage`, with an empty server snapshot so hydration matches. Data is fixed and deterministic.

Lessons: a constant exported from a `"use client"` module (such as a class string) is a client reference when a server component imports it, and `cn()` silently drops it, so pages that use shared style constants must be client components too; the `check-item` import detector also flags `from "…"` inside code samples, so Node samples use `require`; `chart-N` colours differ in lightness between modes, so text on them uses a template variable; build class names out of whole strings (a `border` field next to each `bg` class) because Tailwind cannot see names assembled at runtime.

Accessibility notes: axe (serious and critical) is clean on every page in light and dark, and `scripts/a11y-open-states.ts` scans interacted states (the open search dialog, the feedback box, a filtered reference, an empty search, a clash warning, a speaker dialog, ticket errors, the bag drawer, a promo code, checkout errors, a frozen card, a changed slider, a failed download form). Filters are `aria-pressed` buttons with a polite result count; scrollable tables are focusable regions; galleries and glaze swatches are radio groups; the countdown is hidden from assistive tech and replaced by a sentence that does not change every second.
