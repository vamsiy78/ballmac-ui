Adds the `make_preset` tool. Describe a design (start from a ready-made system, a theme or a code, then a hue, radius, typeface, platform feel or motion) and get back its 16-character code, the install command and a contrast check. Needs the preset address on ui.ballmac.com, so it works with the hosted site and not with an older mirror.
